## 3. 시연 시나리오(데모)

1. 새 차수 "2026-001 Day1 계약 품의" 생성, 필수 5종 기준대장 등록(TC-01).
2. 첨부문서 6개 일괄 업로드: 견적서(TC-02 연결), 사업수행계획서, WBS, 기술협상리스트, 모호한 파일(TC-03 선택), 미분류 스캔본(TC-04 자동등록).
3. 견적서 검토완료(TC-06 준비) → 재업로드 확인 팝업 확인/취소 각각(TC-06·TC-10).
4. 사업수행계획서 보완 필요 지정 → 보완본 재접수(TC-07).
5. 체크 보드에서 종료 상태 확인(TC-09): "필수 5종 중 4종 접수 · 1종 미제출 · 1종 보완 필요".
6. 폴더 내보내기 + 엑셀 대장 내보내기로 마무리.
